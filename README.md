# 星坠之谜 · 文字卡牌RPG

一款零依赖的网页文字/卡牌 RPG。黑暗奇幻背景：星坠之夜，你受命调查雾隐镇北的迷雾矿坑，
在分支剧情与属性检定中推进冒险，用卡牌战斗击败矿坑之王与堕落守塔人。

## 如何运行

**双击 `index.html` 即可游玩**（Chrome / Edge），无需安装任何东西。

进度会自动保存在浏览器本地（localStorage），标题画面可"继续冒险"。

## 玩法

- **剧情推进**：阅读故事、选择分支。`🎲 属性检定` 掷 d20 + 属性×2，达到 DC 即成功；
  力量 / 敏捷 / 智力 / 魅力各有用武之地——点击左侧面板的属性可查看用途说明。
- **卡牌战斗**（类《杀戮尖塔》）：每回合 3 点行动力、抽 5 张牌；敌人头顶会展示意图
  （⚔️攻击 / 🛡️防御 / ⬆️强化 / ☠️诅咒）。状态：中毒 / 虚弱 / 易伤 / 力量。
- **成长**：战斗胜利获得金币、经验，并三选一拿新卡；商店购装备与药水；战后战利品随机。
- **升级祝福**：每次升级除生命上限 +8 外，还可从三道随机祝福中择一——坚韧（生命上限 +12）、
  蛮力/灵巧/慧识/风仪（属性 +1）、涌泉（每场战斗行动力上限 +1，每局一次）、安眠（完全恢复）、
  横财（80 金币）、顿悟（随机卡牌）。升级攒下的祝福会在回到剧情时逐道奉上，也可以都不要；
  头目战结算的升级同样不耽误。
- **矿坑异闻**：矿坑一层新增「🔎 搜寻侧巷与旧工棚」——每次搜寻随机探得一则侧巷轶事：
  倾覆的矿车、星尘苔壁、巷道尽头的矿灯（灯语对上了有惊喜，对错了有战斗）、塌落的窄道、
  空壳的工棚、巷道深处的暗泉。检定成功与失败各有下场，六则异闻每处机缘每次冒险
  只出现一次，全部探访后侧巷就只剩风声。苔壁、矿灯与工棚里各藏着一件新的星尘遗物。
- **林间异闻**：进矿坑之前的岔路口同样藏着故事——「🔎 搜寻岔路口四周」可探得六则荒野轶事：
  猎人的陷阱线、星蜂的空树、猎人的歇脚棚（运气好能学得一手野外自救——【回气】）、
  蛾群夜舞、苔石路标（初代守塔人的指路铭，可与塔门上的诗对读）、巨狼的残骸。
  与矿坑异闻一样，每处机缘每次冒险只出现一次。
- **星尘遗物**：⚱️ 18 件被动遗物，无需装备、整局生效。银铃舌开战上甲、荆棘指环受击反弹、
  王虫的独眼 +1 行动力却每战索取 3 血、回响晶簇每回合多抽 1 张牌、琥珀坠饰在敌人倒下时
  回复生命、雾露指环开战让全场敌人迟缓、锈刺赶棒让你的易伤更深……
  商店有售，更多藏在精英战利品、矿坑异闻与隐秘角落；战斗底栏会亮出你携带的遗物，
  面板"遗物"栏随时查看。
- **冒险笔记**：📓 自动记录任务进度（主线/支线）与听来的情报线索（酒馆传闻、矿监日志、
  托马斯的警告等）。角色面板下方"翻开笔记"或菜单中可随时查阅——谜底往往藏在笔记里。
- **星陨林（支线区域）**：第二章岔路口踏入猎人小径——药婆雾葵的净化泉眼支线、雾角鹿
  遭遇、精英战「林心低语者」，以及与低语做交易的契约分支。你的选择会写进结局尾声。
- **古塔内部**：踏入古塔后不再直面 Boss——星轨大厅的壁画与遗物、观星台的手记与
  星轨罗盘（可获稀有卡【陨星术】）、星影游荡的旋梯、守着【星辉长剑】的星轨石像精英战，
  以及一次性恢复 60% 的星尘泉水。塔下买的大药水，在这里才真正派上用场。
- **第七巷**：矿坑里所有传闻指向的尽头。火焰瓶能烧开搏动的墙——墙后的洞窟里，是
  前六位外乡人的下场，和墙中之物。掷 d20 之外，现在你还可以消耗物品打开新的路。
- **铃语斋**：镇子深处的风铃铺。聋伯的铃一只都不响——"铃声不断，雾就不进镇"，
  铃是锁的一部分。购置【清铃音】与守夜风铃；四职业还各有一张构筑向稀有卡
  （燃血 / 霜甲术 / 淬毒箭雨 / 圣裁）加入奖励池；**忘却之铃**（40 金币）可从牌组移除一张
  卡牌，让套路更纯粹。
- **观星屋与星兆**：镇东头的歪斜窄塔里，占星师薇拉为你 **🔭 观星问卜**（30 金币）——
  群星给出随机一道**星兆**：战星（开战获 2 层力量）、岁星（开战获 6 护甲）、晦星（敌人开战
  带易伤）、流星（首回合 +1 行动力）、财星（金币 +40%）、智星（经验 +40%）、血星（开战
  失血 4 点换经验 +50%）。星兆持续数场战斗、逐场消耗，角色面板"星兆"栏随时查看剩余
  场数。她那里还售 **陨铁护符**（开战力量与护甲）与通用卡【星图解读】，智力检定通过还
  能听她推演星坠之夜的隐秘。
- **淬炼与诅咒**：铁匠铺的炉火可以**淬炼卡牌**（60 金币）——22 种基础卡有更强的
  "+"形态（打击+ / 重斩+ / 火球术+……），同名卡每一张单独淬炼。矿坑一层深处藏着
  **🛕 无面神龛**：献上 30 金币求一次祝圣淬炼、割掌血祭换一张稀有卡，或是掳走供品——
  神龛不评判，它只是记着。而某些交易与贪念会让 **☠️ 诅咒牌** 混进牌组：无法打出，
  只占抽牌位，有的还会在回合结束时索取生命（低语的烙印 / 星蚀之痒 / 盗来的罪疚 /
  星核的饥馑，各有来路）。矿坑入口的泉水可以**洗净诅咒**（40 金币），忘却之铃同样能让它脱手。
- **多周目与难度**：开局在职业之后选择行程——**磨砺（标准）** 或 **迷雾试炼（困难）**：
  敌人生命 ×1.35、伤害 +2，战利品 ×1.25。通关任一结局后，标题画面解锁 **✦ 继承开局**：
  带着上一世的全部星尘遗物与半程金币进入下一周目，敌人的血与爪随周目递增
  （每周目生命 +25%、伤害 +1、奖励 +15%，与难度叠加）。角色面板会显示周目与难度徽章。
- **迷雾回廊（无尽模式）**：通关任一结局后，标题画面解锁 **🌫 迷雾回廊**——选好职业与
  难度，一层层破开越撞越强的雾墙：敌人生命与伤害随层数无限增长，每五层是一场
  **回响头目**战（掘地虫的回响 / 守塔人的回响 / 星轨石像 / 墙中之物轮换镇守），
  胜后可从三件未持有的星尘遗物中挑选一件作回礼；第 5 层起，头目卡也会混入战斗奖励。
  质数层的雾墙根部会裂开 **🚪 侧门**——推开它可绕过战斗，直面六种回廊异变：星辉石碑
  （以血换遗物 / 星辉换经验 / 铜绿换金币）、拾荒者的篝火（休整、星尘骰赌局、来路不明的
  卡牌）、雾中行商（卡牌 / 药水 / 装备，价格随深度上涨）、雾影窃贼（先偷后追，检定夺回）、
  星尘裂隙（多半是甘泉，也可能烫手）、坍塌的暗室（迎战或抢了就跑）。门后是福是祸，难说。
  门厅的星尘泉水每五层涌出一次，营地休整随深度涨价。倒下可从门厅检查点复活，
  **最深纪录跨周目保存**——此行没有结局，只有深度。
- **成就图鉴**：🏆 38 个跨周目成就——三个结局、各区域头目与支线、战斗与收集里程碑、
  图鉴收集向（收录 20 种卡牌 / 集齐全部遗物 / 见过 10 与 15 种敌人）、轮回与难度向
  （完成第 2 / 3 周目、迷雾试炼通关、忘却 3 张卡牌）、淬炼与诅咒向（淬炼 3 张卡牌、
  带诅咒击败头目、洗净 3 张诅咒）、回廊向（破开 5 / 10 / 15 重雾墙、
  穿过 10 扇侧门、遭遇全部 6 种异变）、探索向（触发 5 则矿坑异闻、同时持有 8 件遗物）、
  祝福向（累计择取 3 道升级祝福）、职业与星兆向（星祭司击败头目、累计问卜 3 次）。
  解锁记录独立于存档保存，删除存档 / 通关清档都不影响；标题画面可随时查阅。
- **冒险图鉴**：📖 跨周目收录你的战历——获得过的 69 张卡牌（按通用与四职业分组，带稀有度，
  含 4 张诅咒牌；淬炼变体不占图鉴）、
  持有过的 18 件星尘遗物、击败过的 24 种敌人。未收录的条目以 ？？？ 显示；标题画面、菜单、
  牌组弹窗的"查看全图鉴"均可查阅，删除存档不影响收录进度。
- **三个结局**：星光 / 新王 / 长夜。星核的抉择决定结局——净化（星光，检定失败也仍会净化，
  只是要以血肉为代价）、吸收（新王）、封存（长夜，直接带碎片回镇，不必登上塔顶）。
  支线（救援矿工、酒馆情报、星陨林）会写进尾声的前几段。
- **存档自愈**：读档时会自动清理已失效的卡牌 / 装备 / 物品 / 场景引用并补齐缺失字段，
  被修复的内容会写进日志并弹出提示，不会因为版本更新而卡在白屏。
- **快捷键**：战斗中 `1~9` 出牌，`E` 结束回合；点击剧情文字可跳过打字机动画。
- **移动端**：窄屏（≤760px）与手机横屏下自动切换紧凑布局——顶栏出现 🎒 按钮滑出
  角色面板（使用物品、查看牌组与笔记），战斗手牌改单行横滑的紧凑卡牌，敌人/中栏/
  手牌保证一屏放下互不遮挡；支持刘海屏安全区，触屏去点了双击缩放延迟。
  横屏（矮视口）下日志栏隐藏，战斗信息由浮动数字与 Toast 承载。

## 项目结构

```
index.html        页面骨架
css/style.css     暗黑奇幻主题样式
js/data.js        全部游戏数据：97 张卡牌条目（69 张基础卡含 4 张诅咒 + 28 张淬炼变体）、18 件遗物、24 种敌人、装备/物品/商店、78 个剧情场景（含观星屋、升级祝福、矿坑异闻、林间异闻、无面神龛与迷雾回廊）
js/state.js       存档（含旧存档自愈）、角色、任务/笔记（journal）、效果结算、升级、跨周目成就/图鉴/周目/回廊纪录、难度缩放
js/ui.js          角色面板、打字机、弹窗（笔记/属性/图鉴/牌组·忘却·淬炼·净化）、浮动数字、WebAudio 合成音效
js/story.js       剧情引擎：场景跳转（含升级祝福拦截）、属性检定、分支、观星问卜、淬炼/净化、回廊特殊选项
js/combat.js      卡牌战斗引擎：回合流程、意图 AI、状态、星兆结算、诅咒代价、奖励
js/main.js        标题画面、菜单、读档、死亡画面、快捷键
tools/validate.js 数据一致性校验（node tools/validate.js）
tools/save_test.js 存档自愈 + 战斗回合边界回归（node tools/save_test.js）
tools/*_test.py   Playwright 浏览器测试（冒烟 / 深度通关 / 移动端 / 冒险图鉴 / 多周目 / 迷雾回廊 / 回廊异变 / 淬炼与诅咒 / 矿坑异闻 / 林间异闻 / 升级祝福 / 星祭司与观星屋）
```

## 开发与测试

```bash
node tools/validate.js      # 数据一致性校验（ID 引用 / 语法 / 逻辑冒烟）
node tools/save_test.js     # 存档自愈 + 战斗边界回归（53 组断言，无需浏览器）
 python tools/smoke_test.py  # Playwright 浏览器冒烟测试（需 msedge）
 python tools/mobile_test.py # 移动端视口测试（竖屏/SE/横屏 + 布局断言 + 截图）
 python tools/codex_test.py  # 冒险图鉴测试（三栏弹窗 / 收录钩子 / 跨周目持久 / 图鉴成就）
 python tools/ngplus_test.py # 多周目测试（难度选择 / NG+ 继承 / 敌人缩放 / 忘却之铃 / 轮回成就）
 python tools/endless_test.py # 迷雾回廊测试（入口解锁 / 层数缩放 / 回响头目 / 遗物回礼 / 纪录持久）
 python tools/endless_ev_test.py # 回廊异变测试（侧门规则 / 六种异变收益与代价 / 行商货架 / 异变成就）
 python tools/forge_test.py  # 淬炼与诅咒测试（铁匠铺淬炼 / 无面神龛 / 诅咒不可打出 / 回合末代价 / 泉水净化 / 图鉴口径）
 python tools/deep_test.py   # 全场景遍历 + 两结局通关 + 星陨林/第七巷/古塔内部/铃语斋 + 成就图鉴 + 死亡复活
 python tools/stargazer_test.py # 星祭司与观星屋测试（第四职业开局 / 问卜星兆 / 逐场消耗 / 开战加护 / 圣裁 / 成就）
```

`tools/validate.js` 检查 ID 引用，`tools/save_test.js` 检查读档健壮性与回合边界
（重洗牌、状态递减、护甲清零、放弃战斗后的异步安全）——两者都是纯 Node，无依赖。

扩展新内容只需编辑 `js/data.js`：加卡牌往 `DATA.CARDS` 加条目、加敌人往 `DATA.ENEMIES`
并挂进 `DATA.GROUPS`、加遗物往 `DATA.RELICS` 写条目（效果字段由引擎钩子自动结算，购买处
用 `show: (s) => !hasRelic(s, 'id')` 防重复）、加剧情往 `DATA.SCENES` 写场景（支持函数文本、
检定、战斗触发、onEnter 钩子）。新增任务/笔记：先在 `DATA.QUESTS` / `DATA.NOTES` 定义，再在场景钩子里
调 `Quest.add(state,'id')` / `Note.add(state,'id')`，或直接写在选项效果上
`fx: { quest: 'id', note: 'id' }`。跑一遍 `tools/validate.js` 即可确认引用无误。
新加入的卡牌 / 遗物 / 敌人会被冒险图鉴自动纳入收录范围（获得 / 持有 / 击败时登记），无需额外注册。
